# Объяснение структуры:
1. Core (Бизнес-логика):

 - entities/ – cущности доменной модели;
 - services/ – cервисы, управляющие логикой работы (поиск мест, ранжирование, опросы);
 - repositories/ – репозитории для работы с БД;
 - unit_of_work.py – управление транзакциями в БД.

2. Application (Use Case Layer):
 - use_cases/ – реализации конкретных сценариев использования

3. Infrastructure (Доступ к данным и API):

 - db/ – база данных, SQLAlchemy-модели и подключение;
 - external/ – интеграция с внешними API.

4. Presentation (UI Layer, Telegram Bot):

 - bot/ – бот и его обработчики;
 - ui/ – вспомогательный слой для работы с сообщениями и клавиатурами.

5. Корневые файлы:

 - config.py – конфигурация (настройки, API-ключи);
 - .env – переменные окружения;
 - requirements.txt – зависимости;
 - run.py – запуск бота.

Файлы __init__.py в каждой папке делают эту папку модулем, позволяя импортировать его содержимое и просто удобные импорты)


# Пример простого сценария работы бота:

1. Пользователь отправляет команду /lunch в Telegram-чате.
2. Бот получает сообщение и передает его в обработчик.
3. Обработчик вызывает use case поиска ресторанов.
4. Use case запрашивает список ресторанов через сервис.
5. Сервис обращается к внешнему API карт и получает список мест.
6. Use case передает список в сервис ранжирования.
7. Сервис ранжирования сортирует рестораны и передает обратно в use case.
8. Use case отправляет список ресторанов в обработчик бота.
9. Бот создает опрос и отправляет его в групповой чат.
10. Пользователи голосуют, бот фиксирует результаты.
11. Бот объявляет выбранное место и предлагает забронировать столик.
12. После посещения пользователи оценивают ресторан, данные обновляются.

# Как взаимодействуют слои

1. Presentation (Бот) → получает команду, передает в Use Case Layer.

2. Use Case Layer → вызывает Core Layer (сервисы, доменные модели).

3. Core Layer → обрабатывает данные, обращается к Infrastructure Layer (API, БД).

4. Infrastructure Layer → получает данные (из карт, погоды, БД) и передает в Core Layer.

5. Core Layer → обрабатывает, ранжирует, передает результат в Use Case Layer.

6. Use Case Layer → возвращает результат в Presentation (бот).

7. Бот → отправляет пользователям информацию.
